# Post LinkedIn — KronoStore

🚀 **KronoStore** — Projeto completo de e-commerce full-stack

Desenvolvi do zero uma plataforma de e-commerce focada em hardware e periféricos de alto desempenho, aplicando arquitetura hexagonal e as melhores práticas do mercado.

**Stack utilizada:**
- ⚡ API com **Node.js + Fastify + TypeScript**
- 🎨 Frontend em **Next.js 16 (App Router) + React 19**
- 🗄️ **PostgreSQL** com **Drizzle ORM**
- 🔴 Cache e filas com **Redis + BullMQ**
- 🔐 Autenticação via **Better Auth**
- 💳 Pagamentos com **Stripe** (cartão, PIX e boleto)
- 📦 Storage com **MinIO** (S3-compatible)
- ✅ Validação com **Zod**
- 🧪 Testes com **Vitest + Playwright**
- 🔄 CI/CD com **GitHub Actions**

**O que aprendi com este projeto:**
- Arquitetura hexagonal (Ports & Adapters) com domínio isolado
- Integração com gateway de pagamentos real (Stripe)
- Idempotência e proteção contra double-submit em fluxos críticos
- Testes E2E cobrindo o fluxo completo de compra
- Pipeline de CI com jobs paralelos (lint, typecheck, testes, build)
